# 별장 청소 일일 배차 도구 (v0)

전국에 분산된 독채 별장의 청소를 매일 배차하는 내부 운영 도구 프로토타입.
현장 운영 매니저 1인이 매일 아침 "오늘 어느 별장을 청소해야 하고, 어떤 순서로 돌아야 하는가"를
결정하는 데 쓰는 것을 상정했다.

**데모:** https://clddy.github.io/mozaiq-dispatch/ (모바일 뷰포트 기준)

---

## 무엇을 푸는가

별장 청소 배차에는 서로 당기는 제약이 동시에 걸린다.

- 오늘 체크인이 있는 별장은 **검수 버퍼를 포함해 정해진 시각까지** 끝나야 한다
- 체크인이 없는 별장도 무한정 미룰 수 없다 (공실 방치 한도)
- 청소부는 한정돼 있고, 차량은 한 대이며, 별장은 서로 멀다
- 이동시간을 줄이려고 순서를 바꾸면 데드라인이 깨질 수 있다

이 도구는 그 판단을 **긴급도 분류 → 순서 최적화 → 타임라인 제시** 세 단계로 나눠 처리한다.
계산이 감당하지 못하는 부분(피로도, 기상, 파손 등)은 숨기지 않고 화면 하단에 명시한다.

## 운영 모드 두 가지

| | 동행형 | 셔틀형 (기본) |
|---|---|---|
| 이동 | 팀 전체가 한 차로 함께 | 기사가 청소부를 드롭/픽업 |
| 청소 | 순차 (한 번에 한 채) | 병렬 (여러 채 동시) |
| 최적화 | 순열 완전탐색 (≤8곳), 그 이상은 NN+2-opt | 우선순위 휴리스틱 + 2-opt |
| 특징 | 계산이 단순, 처리량 낮음 | 처리량 높음, 기사 대기 발생 |

셔틀형에서 기사가 노는 **대기 구간을 타임라인에 명시**하는 것이 핵심이다.
그 공백이 곧 "묶어가기"로 유예 별장을 하나 더 태울 수 있는 여지이기 때문이다.

## 화면 흐름

1. **입력** — 오늘 체크아웃한 별장을 탭해 선택, 다음 체크인 시점과 오염도를 지정
2. **판단** — 긴급 / 권장 / 유예 가능 분류와 각 판단의 사유,
   그리고 묶어가기 추천 (추가 이동비용 / 단독 왕복비용 / 절약분 3개 숫자를 함께 제시)
3. **동선** — 셔틀 타임라인(드롭·픽업·대기), 지도 경로, 총 이동/청소시간과 완료 예정 시각

## 알고리즘

**청소시간 추정** — `(기본 + 평수×계수 + 부대시설 가산) × 오염도 배수`, 5분 단위 올림

**긴급도 분류** — 다음 체크인이 오늘/내일이면 긴급, 2~3일 후면 권장, 없으면 유예.
단 공실 경과일이 한도에 도달하면 유예에서 긴급으로 승격한다.

**동행형 순서** — 경유지 8곳 이하는 순열 완전탐색. 데드라인 위반 순열에는 큰 페널티를 주어
"이동시간은 짧지만 체크인을 놓치는" 답을 배제한다. 9곳 이상은 최근접+2-opt로 폴백.

**셔틀형 스케줄** — 데드라인 우선 정렬 → 최근접 드롭 라운드 → 픽업 가능 시각이 가장 빠른
별장부터 픽업하며 미배치 작업이 있으면 즉시 재드롭 → 2-opt 개선.
데드라인 위반이 남으면 해당 별장을 드롭 순서 앞으로 당겨 재계산하고,
그래도 안 되면 결과에 경고로 노출한다 (숨기지 않는다).

**묶어가기 추천** — 후보를 넣어 스케줄을 재계산한 우회비용이 단독 왕복비용의 절반 미만이고,
근무시간 내 완료되며, 기존 별장의 데드라인 위반이 새로 생기지 않을 때만 추천한다.

## 디자인

MOZAIQ 브랜드 사이트(mozaiq.co.kr)에서 실측한 값을 그대로 쓴다.
베이스는 따뜻한 아이보리 `#FFFEF5`에 잉크 `#111111`, CTA는 브론즈 `#8E7042`.
다크(`#111111`)는 전면이 아니라 헤더와 지도 같은 **부분**에만 얹어 원본의 리듬을 따른다.
헤딩은 나눔명조, 본문은 Pretendard에 음수 자간(-0.04em)을 준다.

## 기술 스택

Vite + React (단일 페이지) · Leaflet + CARTO 타일 · 상태는 `useState`만 · 백엔드 없음

## 설계상 지켜야 할 것

- **모든 튜닝 파라미터는 [`src/config.js`](src/config.js) 한 곳에** — 매직 넘버 금지.
  청소시간 계수, 근무시간, 검수 버퍼, 차량 정원, 추천 임계값이 전부 여기 있다.
- **이동시간은 [`src/logic/travel.js`](src/logic/travel.js)의 `travelMinutes` 하나만 통해 얻는다.**
  v0는 직선거리 × 보정계수 근사이고, 카카오맵 API 연동 시 이 함수 본문만 교체한다.
- **로직 모듈(`src/logic/`)은 React를 모른다.** 순수 함수라 단위 테스트가 가능하다.
- **별장 데이터는 [`src/data/villas.json`](src/data/villas.json) 하나만 갈아끼우면 된다.**
  현재 값은 MOZAIQ가 공개한 운영 별장 24채(서울·가평·홍천·양평·용인·제주)의
  이름/지역/평수/시설을 옮긴 것이다. 좌표는 실제 주소가 비공개이므로 읍면동 단위
  근사값을 쓰고, 그 사실을 `coord_precision: "region"`으로 명시한다.
